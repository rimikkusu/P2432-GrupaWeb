# Grupa P2432 — albumul nostru digital

Landing page pentru cei 35 de colegi din lista primita, cu fotografiile furnizate in folderul `Colegi`. Design pixel-art in culorile `#355070`, `#6D597A`, `#B56576`, `#E56B6F` si `#EAAC8B`.

## Deschidere

Deschide `index.html` in browser. Site-ul functioneaza local, fara instalare si fara conexiune la internet.

## Fisiere

- `index.html` — numele si cele 35 de fise, fiecare cu trei propozitii.
- `style.css` — culori, rame pixelate si adaptarea la telefon.
- `Colegi/` — fotografiile colegilor, folosite in fise.
- `assets/fonts/` — fontul CutePixel, extras din arhiva furnizata.

Tot textul site-ului foloseste CutePixel, fara diacritice.

## Personalizare

Cauta numele colegului in `index.html` si modifica textul din elementul `student-description`. Descrierile actuale sunt exemple fictive; nu reprezinta informatii verificate despre colegi. Inlocuieste-le cu cel putin trei propozitii reale pentru fiecare persoana.

Pentru a schimba o fotografie, modifica atributul `src` al imaginii din fisa colegului. Fisierele sunt legate direct din folderul `Colegi`, care trebuie pastrat alaturi de `index.html`.

Site-ul foloseste HTML si CSS. Fisele sunt afisate direct in pagina, fara JavaScript.
